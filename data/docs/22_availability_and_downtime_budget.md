# Runbook 22 (SYNTHETIC): Availability and Downtime Budget

Availability is measured per cell per calendar month.
- A 99.9% target allows about 43.2 minutes of downtime in a 30-day month.
- A 99.95% target allows about 21.6 minutes.
Planned maintenance inside approved windows is excluded from the calculation.
Unplanned downtime, including sleeping-cell time once detected, counts in full.
